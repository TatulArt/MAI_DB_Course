# Предметная область: интернет-магазин

Магазин продаёт товары, сгруппированные по категориям. Клиент регистрируется, оформляет заказ из одной или нескольких позиций (товар + количество) и оплачивает его, возможно частями. Заказ проходит статусы: `new` → `paid` → `shipped` → `delivered` (или `cancelled`). БД хранит и текущий статус заказа, и историю его смен.

## Сущности

| Таблица | Что хранит |
|---|---|
| `customers` | клиенты |
| `categories` | категории товаров |
| `products` | товары, цена, остаток |
| `orders` | заказы клиентов, текущий статус |
| `order_items` | позиции заказа (связь заказ ↔ товар) |
| `payments` | платежи по заказам |
| `order_status_history` | история смены статусов заказа |
